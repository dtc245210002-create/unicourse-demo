# UniCourse

Demo trợ lý đăng ký học phần cho dự án Software Interface Design. Dữ liệu học phần và tài khoản là giả lập; chưa có kết quả nghiên cứu sinh viên.

## Chạy demo

Mở `unicourse-demo/index.html` bằng Chrome hoặc Edge. Giữ `shared/catalog.js` cùng cấp với thư mục `unicourse-demo`. Không cần API key, cài đặt hoặc backend.

Có tìm kiếm, lọc, chi tiết, tiên quyết, giỏ, lịch, phát hiện trùng, lớp thay thế, gợi ý theo ràng buộc, xác nhận demo, lịch sử cục bộ và tải ICS. Số tiết 1–12 đã cố định ở cột trái.

## Google AI Studio

Nhập repository từ GitHub trong chế độ Build. Điểm vào: `unicourse-demo/index.html`. Giữ nguyên giao diện và hành vi; chỉ điều chỉnh cấu hình chạy khi cần. Không tự thêm Gemini API hay tuyên bố đăng ký thật tại trường.

## Tệp bàn giao cục bộ

Báo cáo Word/PDF 29 trang nằm trong `report`. Gói Figma v2, plugin và 23 ảnh nằm trong `figma-unicourse`. Hai thư mục này chỉ giữ cục bộ và không được commit trong repository demo. Figma v2 chưa được xác nhận chạy native đủ ba luồng.
